# **App Name**: TicketFlow

## Core Features:

- Event Discovery: Enable users to browse events, filter by date, location, and category, and search for specific events.
- Ticket Purchase: Allow users to select ticket categories, view pricing, and proceed through a checkout process.
- Event Management: Provide admins with tools to create and manage events, set up ticket categories and pricing, and manage discount codes.

## Style Guidelines:

- Primary color: Dark Blue (#1A202C) for a professional look.
- Secondary color: Light Gray (#EDF2F7) for backgrounds and subtle accents.
- Accent: Teal (#4DC0B5) for interactive elements and highlights.
- Clean, modern layout with clear sections for event browsing, details, and checkout.
- Consistent use of simple, outline-style icons for categories and actions.
- Subtle transitions and animations to enhance user experience during navigation and interactions.
